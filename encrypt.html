Telegram bot — encrypt / decrypt

Offline page, no libraries, no network. Same format as telegram_bot.py / encrypt.py: enc:v1:<base64(salt 16 bytes | iv 12 bytes | AES-GCM ciphertext+tag)>, key = PBKDF2-HMAC-SHA256(passphrase, salt, 100,000 iterations, 32 bytes).

WebCrypto needs a secure context: open this file directly (file://) or serve it with python -m http.server and open http://localhost:8000/encrypt.html.

Verified 2026-11-17 with node v24: a string encrypted by the Python side decrypts here, and a string encrypted here decrypts on the Python side (see test_telegram_bot.py).
